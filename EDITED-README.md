# The Core 2.0 — Polished Concept Build

This version keeps the existing React/Vite + backend functionality and upgrades the public-facing website into a premium commercial gym concept.

## Main changes
- New premium, responsive landing page
- Mobile navigation
- Cinematic hero and stronger CTA hierarchy
- About / benefits / facilities sections
- Membership enquiry cards linked to WhatsApp
- Trial booking section with safer wording (no unverified "free trial" claim)
- Conversion / digital platform section
- Improved contact section, directions CTA and footer
- SEO/meta improvements in `client/index.html`
- Existing Join, Login, Admin and Check-in routes retained

## Run the frontend
```bash
cd client
npm install
npm run dev
```

## Build the frontend
```bash
cd client
npm install
npm run build
```

## Run the backend
Follow the existing project README and `.env.example` inside `server/`.

## Important before a real launch
The public demo intentionally avoids inventing membership prices, awards or testimonials. Replace concept stock imagery and any facility descriptions with approved The Core 2.0 photos/details before publishing as an official website.
